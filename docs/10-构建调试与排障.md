## 7. 排障矩阵

| 症状 | 先查 | 常见原因 / 处理 |
|---|---|---|
| **启动失败** | 页脚 "启动失败"+原因；`settings\*.json` 是否合法 | JSON 语法错/编码非 UTF-8；`ActiveProject` 全是空壳；`LoadDirectory` 跳过坏文件但全空 |
| **设备"未连接"** | 状态栏 `LastError`（`DescribeFailure` 已带地址） | IP/端口不可达、防火墙、502 被占；串口号错/被占（`UnauthorizedAccessException`）/波特率不匹配；RTU-over-TCP 配成了 `ModbusTCP` |
| **"已连接(无数据)"** | 组 `Start/Length`、功能码区、从站地址 | 组长度 0 或跨度算不出；地址区间不在从站映射里；从站回异常码被当失败 |
| **数值离谱（8.5E-41 / 巨大数）** | 设备 `DataFormat`/`WordOrder` | 现场 RTU-over-TCP 是 `"DataFormat":"2"`(CDAB)；漏写=默认 ABCD → Float 全错 |
| **某点一直 `--` / 未采集** | 该变量 `Start/VarType/Length` | 地址解析失败（`TryParseVarAddress` 规则见 02 篇 4.2）；`rel<0` 越界；类型长度超组范围；`200.05` 被误当小数的老 bug 已修，确认用新二进制 |
| **断线后数字"冻结"不变** | — | **这应当不存在**：新实现断线发 `NotCollected` → 显示 `--`。若冻结，说明跑了旧 exe 或 `Publish` 路径被绕过 |
| **报警不触发/不消除** | 变量 `High/LowAlarmEnable`+阈值+死区；`AlarmService` 是否 Build | 死区内保持原状态是正常；`null/NaN` 值不改变状态；重启后状态机归 Normal（历史需查 `alarms.db`） |
| **历史曲线没数据** | `ArchiveEnable`、`ArchiveIntervalSeconds`、`history.db` 的 `VarDict/History` | 变量未开启归档；质量 Bad/NotCollected/NaN 不写（`History.Value NOT NULL`）；WAL 未合并时用 sqlite 工具查要连对文件 |
| **写入拒绝** | `WriteResultText` / MCP 返回的原因 | 未登录或无 `CanWrite`；「参数设置」未勾"允许写入"；组不可写（`IsWritable`/组名无 设定/参数/Set/SP）；类型 64 位或 String 不支持；限速 `WriteMinIntervalMs=800`；地址不可写 |
| **MCP 连不上** | `data\mcp_debug.log`、设置窗口端点 | `McpEnabled=0` 或端口 0；端口被独立 `KyjScada.Mcp.exe` 占用；改设置后应自动重启（看 `RestartMcpHost`）；`Stop` 曾在 UI 线程死锁，现已 `Task.Run` 修复——若仍卡，确认跑的是新 `App.exe` |
| **MCP 写入报错但界面无回显** | `McpWrite` 是否 `Dispatcher.Invoke` | HTTP 线程直接碰 `_gate` 会出并发问题；回显写 `WriteResultText` |
| **界面卡顿** | `data\ui-latency.log`（`--ui-diag`） | `OnUiTick` 里 `Items.Refresh()`（**禁止**，已删过一次别加回）；在 tick/Click 里查大库；趋势查询必须后台 |
| **切设备后另一台停了** | `OnAcqTick` 多设备汇总 | `ApplyDevice` 不应 `StopAll`；`EnsureCoordinator` 是单例管全部 pipeline |
| **build 报 MSB3027 锁文件** | — | `taskkill /IM KyjScada.App.exe /F`，等句柄释放再 build |
| **`dotnet test` 跑不出结果** | — | 本仓库测试是控制台 exe，直接运行 `*.Tests.exe` |
| **配置改了没生效** | 改的是哪个目录？ | 必须改 **exe 旁 `settings\`**；源码树无此目录。界面改字节序写回 `DeviceFiles` 映射的那个文件 |

## 8. SQLite 手查（排障用）

```powershell
# 需要 sqlite3.exe（或用 DB Browser for SQLite 打开 data\history.db）
sqlite3 .\KyjScada.App\bin\Debug\net8.0-windows\data\history.db `
  "SELECT d.VarName, h.SampleTime, h.Value FROM History h JOIN VarDict d ON d.VarId=h.VarId ORDER BY h.Id DESC LIMIT 5;"
sqlite3 ...\alarms.db "SELECT Id,VarName,Direction,IsTrigger,Value,OccurredAt,AckAt FROM AlarmEvents ORDER BY Id DESC LIMIT 10;"
sqlite3 ...\users.db  "SELECT Id,UserName,IsActive,Permissions,LastLoginAt FROM Users;"
```

WAL 模式下 `-wal` 有最新未 checkpoint 数据；程序正常关闭会合并。**不要删除 `-wal/-shm`**。

## 9. 截图 / UIA 自动化注意（Windows）

- 全屏：`powershell -ExecutionPolicy Bypass -File D:\DeepSeekHarness\agent\capture-desktop.ps1 -FullScreen`。
- 按进程抓窗：`capture-desktop.ps1 -WindowPid (Get-Process KyjScada.App).Id`。
- `-WindowTitle '系统设置'` 对 **`ShowDialog` 模态窗可能失败**（不在主窗 UIA 子树）。
  可靠做法：`EnumWindows + GetWindowThreadProcessId` 匹配 pid + 标题（用 `[DllImport("user32.dll", CharSet=CharSet.Unicode)]` 的 `GetWindowTextW`），再 `AutomationElement.FromHandle`。
- 最大化 WPF 窗在 1366×768 上外扩 8 px（窗口 rect `-8,-8,1382,784`），截图像素坐标 ≈ UIA 坐标 + 8。
- 密码框：剪贴板 + `SendKeys '^a'/'^v'`。
